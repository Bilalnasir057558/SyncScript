# SyncScript

## How to Work 
### Step 1: Clone Repo
1. git clone https://github.com/Bilalnasir057558/SyncScript.git
2. cd SyncScript

### Step 2: Create New Branch
1. git checkout -b feature/login-page

👉 Naming:
- feature/...
- bugfix/...

### Step 3: Do Your Work
Edit files

### Step 4: Commit Changes
1. git add .
2. git commit -m "Added login page UI"

### Step 5: Push Branch
1. git push origin feature/login-page

### Step 6: Create Pull Request (PR)
1. Go to GitHub
2. Click Compare & Pull Request
3. Add description
4. Submit PR

### Step 7: Review & Approve
Other members:
- Review code
- Click Approve


### Step 8: Merge
After approval:
- Click Merge PR

##  Always Update Your Code

#### Before starting work:
- git checkout main
- git pull origin main

Then:
- git checkout -b new-feature

###  Common Mistakes (Avoid These)

❌ Don’t work directly on main
❌ Don’t overwrite others' code
❌ Always pull latest code before working
